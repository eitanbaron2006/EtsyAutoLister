# Listing Extras — per-product-type info images

Drop your AI-generated product-info images (e.g. "What's included", ratio
charts, "How to print", "Printable product only — no physical item") into the
folder matching the product type:

- `printable_wallart/` — Printable Wall Art Canvas
- `png_graphics/` — PNG Artwork Clipart Pack
- `presets/` — Lightroom Preset Bundle
- `planners/` — Agenda / E-Book Planner

Rules:
- Formats: PNG / JPG / JPEG / WEBP.
- Files are attached to EVERY product of that type, after the mockups, in
  alphabetical order — prefix with numbers to control ordering
  (`01-whats-included.png`, `02-ratios.png`, ...).
- Etsy allows up to 20 photos per listing; the app trims overflow
  (mockups first, then these extras, then source images).
